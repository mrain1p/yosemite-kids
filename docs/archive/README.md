# Archive — finished history

Design records from rounds that have shipped. Nothing here is a plan any
more: each file says what was decided and why at the time, and the code has
moved on since. Read one when a comment in the code cites it for a decision
(`docs/archive/PLAN-sync.md` for the merge, `PLAN-hub-parity.md` for the
watch ledger, `PLAN-crawl.md` for the shared crawler). Do not update them —
a change of mind belongs in `docs/ROADMAP.md`, the one forward-looking
document, and the record of what shipped in `docs/FORK-NOTES.md`.

Guard 66 keeps `docs/` itself free of `PLAN-*.md` files: a plan that has
shipped moves here, and a plan that has not yet is a roadmap section, not
a file.
